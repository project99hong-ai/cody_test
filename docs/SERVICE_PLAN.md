# AX Ground 서비스 기획서

## 1. 서비스 개요
- 서비스명: **AX Ground**
- 정의: 기업의 AI 활용 현황과 고민을 입력하면 AI가 AX 전환 우선순위와 다음 액션을 정리해주는 기업용 간이상담 웹 서비스
- 목적: AI/AX에 관심은 있지만 어디서 시작할지 모르는 기업 담당자가 교육, 자동화, 전략·PoC 중 어떤 접근이 필요한지 빠르게 이해하도록 돕는다.
- 핵심 메시지: **AI 교육부터 자동화, AX 전환까지. 목표에 더 빠르게 도달하도록 돕는다.**

## 2. 타겟 사용자
- AI/AX 도입을 검토하는 중소·중견기업 실무자 및 의사결정자
- 사내 AI 교육이 필요한 HR/L&D 담당자
- 반복 업무 자동화를 고민하는 운영/기획 담당자
- AI PoC를 시작하려는 신사업/전략 담당자

## 3. 주요 사용자 문제
- 어떤 업무부터 AI를 적용해야 할지 모른다.
- 교육, 자동화, 컨설팅 중 무엇이 먼저인지 판단하기 어렵다.
- 기술 도입이 실제 업무 개선으로 이어질지 불확실하다.
- 내부 제안에 사용할 현실적인 다음 액션이 필요하다.

## 4. 페이지/섹션 구성
1. Home / Hero — 가치 제안과 CTA
2. Services — AI 교육, 업무 자동화, AX 전략·PoC
3. Process — Discover → Design → Pilot → Scale
4. AI Diagnosis — 실제 AI 간이상담 기능
5. FAQ — 도입 전 질문
6. Contact CTA — 상담 전환

## 5. AI 기능
### 기능명
3분 AX 간이진단

### 입력
- 회사 규모
- 담당 역할
- AX 목표
- 현재 AI 활용 수준
- 해결하고 싶은 업무 문제

### 출력
1. 현재 상태
2. 최우선 과제
3. 2주 액션
4. 추천 상담 영역

### 실패 처리
- 필수값 누락: 프론트 검증
- 고민 10자 미만: 프론트/백엔드 검증
- 서버 입력 오류: 400
- API 키 미설정: 503
- AI 공급자 오류: 502
- 20초 이상 지연: AbortController로 요청 중단

## 6. UX/UI 방향
- B2B SaaS와 컨설팅 회사의 신뢰감을 결합
- 다크 네이비/그린 계열 기반, 라임·민트 Accent
- 큰 타이포, 넓은 여백, 카드형 정보 구조
- 반응형 모바일 우선 고려
- 스크롤 진행률, reveal, parallax, 오비트, hover micro interaction 적용
- prefers-reduced-motion 지원

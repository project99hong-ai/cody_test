## 테스트 케이스
1. 정상: 모든 값을 입력하고 10자 이상 고민 작성 → 결과 4개 항목 출력
2. 빈 입력: 한 항목 미입력 → 안내 메시지
3. 짧은 입력: 고민 10자 미만 → 안내 메시지
4. API 키 없음: 503 안내 메시지
5. 응답 지연: 20초 초과 → 타임아웃 안내
6. 반응형: 390px / 1440px 너비에서 화면 확인
